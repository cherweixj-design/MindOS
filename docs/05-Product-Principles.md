# Product Principles

## 1. Workspace First

MindOS is an AI Workspace, not an AI Chat application.

## 2. Chinese First

Chinese is the default output language.

English output is optional.

## 3. Explainable AI

AI should explain why, not only provide answers.

## 4. Local First

User data belongs to the user.

Documents should stay local whenever possible.

## 5. Simplicity

Keep everything simple.

Avoid unnecessary complexity.
